Round 3
FIRST QUARTER
1. This general crossed the Rubicon in 49 BC, starting a civil war. For the point, name this Roman
who was assassinated on the Ides of March.
<b>ANSWER:</b> Gaius Julius <b>Caesar</b>
2. This document was signed at Runnymede in 1215. For the point, name this English charter.
<b>ANSWER:</b> <b>Magna Carta</b> [accept Great Charter]
3. This city was the capital of the Aztec Empire. For the point, name this city on Lake Texcoco.
<b>ANSWER:</b> <b>Tenochtitlan</b>
4. This queen ruled England during the defeat of the Spanish Armada. For the point, name this Tudor
monarch.
<b>ANSWER:</b> <b>Elizabeth I</b> [prompt on Elizabeth]
5. This 1803 deal doubled the size of the United States. For the point, name this purchase from France.
<b>ANSWER:</b> <b>Louisiana</b> Purchase

6. This Mughal emperor built the Taj Mahal. For the point, name this ruler.
<b>ANSWER:</b> <b>Shah Jahan</b>
7. This leader led the Salt March in 1930. For the point, name this Indian activist.
<b>ANSWER:</b> Mohandas <b>Gandhi</b>
8. This wall fell in November 1989. For the point, name this barrier in a German city.
<b>ANSWER:</b> <b>Berlin Wall</b>
9. This ship sank in April 1912 after hitting an iceberg. For the point, name this liner.
<b>ANSWER:</b> RMS <b>Titanic</b>
10. This empire was ruled from Constantinople after 330. For the point, name this eastern Roman state.
<b>ANSWER:</b> <b>Byzantine</b> Empire [or Eastern Roman Empire]
SECOND QUARTER
1. This treaty ended the Thirty Years' War in 1648. Its name comes from a region of western Germany.
For the point, name this set of treaties.
<b>ANSWER:</b> Peace of <b>Westphalia</b>
BONUS: This French cardinal's diplomacy shaped the late years of that war. Name this chief minister of
Louis XIII.
<b>ANSWER:</b> Cardinal <b>Richelieu</b>
2. This Carthaginian general crossed the Alps with elephants. For the point, name him.
<b>ANSWER:</b> <b>Hannibal</b> Barca
BONUS: Hannibal won this 216 BC battle, a classic double envelopment.
<b>ANSWER:</b> Battle of <b>Cannae</b>
3. This Ethiopian emperor won the Battle of Adwa in 1896. For the point, name him.
<b>ANSWER:</b> <b>Menelik II</b>
BONUS: Adwa was fought against the army of this European country.
<b>ANSWER:</b> <b>Italy</b>
4. This Prussian chancellor unified Germany in 1871. For the point, name this "Iron Chancellor."
<b>ANSWER:</b> Otto von <b>Bismarck</b>
BONUS: Bismarck hosted this 1884 conference on claims in Africa.
<b>ANSWER:</b> <b>Berlin</b> Conference
5. This 1954 Supreme Court case ended legal school segregation. For the point, name this case.
<b>ANSWER:</b> <b>Brown</b> v. Board of Education
BONUS: This NAACP lawyer argued Brown and later joined the Court.
<b>ANSWER:</b> Thurgood <b>Marshall</b>
6. This Soviet leader introduced glasnost. For the point, name him.
<b>ANSWER:</b> Mikhail <b>Gorbachev</b>
BONUS: Gorbachev's other reform, a restructuring of the economy, had this name.
<b>ANSWER:</b> <b>perestroika</b>
7. This Mongol leader founded the Yuan dynasty. For the point, name this grandson of Genghis Khan.
<b>ANSWER:</b> <b>Kublai</b> Khan
BONUS: Kublai Khan moved his capital to this city, then called Dadu.
<b>ANSWER:</b> <b>Beijing</b> [accept Khanbaliq]
8. This 1789 event began when a Paris crowd stormed a fortress. For the point, name this revolution.
<b>ANSWER:</b> <b>French</b> Revolution
BONUS: That fortress, stormed on July 14, had this name.
<b>ANSWER:</b> <b>Bastille</b>
THIRD QUARTER
The categories are Ancient Rome, Explorers, and Twentieth-Century Asia.
Ancient Rome
1. Name the first emperor of Rome.
<b>ANSWER:</b> <b>Augustus</b> [accept Octavian]
2. Name the volcano that buried Pompeii in 79 AD.
<b>ANSWER:</b> Mount <b>Vesuvius</b>
3. Name the river the Romans called the Tiberis.
<b>ANSWER:</b> <b>Tiber</b>
4. Name the general who defeated Hannibal at Zama.
<b>ANSWER:</b> <b>Scipio</b> Africanus
5. Name the assemblies of Rome's aristocrats.
<b>ANSWER:</b> <b>Senate</b>
6. Name the emperor who built a wall across northern Britain.
<b>ANSWER:</b> <b>Hadrian</b>
7. Name the Roman road that ran from Rome to Brindisi.
<b>ANSWER:</b> <b>Appian</b> Way [or Via
Appia]
8. Name the emperor who split the empire into a tetrarchy.
<b>ANSWER:</b> <b>Diocletian</b>
Explorers
1. Name the Portuguese explorer who reached India by sea in 1498.
<b>ANSWER:</b> Vasco da <b>Gama</b>
2. Name the explorer whose expedition first sailed around the world.
<b>ANSWER:</b> Ferdinand <b>Magellan</b>
3. Name the Venetian who described the court of Kublai Khan.
<b>ANSWER:</b> Marco <b>Polo</b>
4. Name the Norse explorer who reached Vinland.
<b>ANSWER:</b> Leif <b>Erikson</b>
5. Name the Moroccan traveler who wrote the Rihla.
<b>ANSWER:</b> Ibn <b>Battuta</b>
6. Name the Chinese admiral of the treasure voyages.
<b>ANSWER:</b> <b>Zheng He</b>
7. Name the explorer who first reached the South Pole.
<b>ANSWER:</b> Roald <b>Amundsen</b>
8. Name the captain killed in Hawaii in 1779.
<b>ANSWER:</b> James <b>Cook</b>

FOURTH QUARTER
1. A treaty signed at this place in 1919 contained a "war guilt" clause, Article 231. (+) It was signed in
a hall of mirrors in a former royal palace. (*) For the point, name this palace near Paris.
<b>ANSWER:</b> Palace of <b>Versailles</b>
2. This ruler issued a code that included "an eye for an eye." (+) He ruled from Babylon. For the point,
name this king.
<b>ANSWER:</b> <b>Hammurabi</b>
3. This conflict included the Battle of Agincourt. (+) Joan of Arc fought in it. For the point, name this
war between England and France.
<b>ANSWER:</b> <b>Hundred Years'</b> War
4. This leader was released from prison in 1990. (+) He became president of South Africa in 1994. For
the point, name him.
<b>ANSWER:</b> Nelson <b>Mandela</b>
5. This canal opened in 1869. (+) Egypt's Nasser nationalized it in 1956. For the point, name it.
<b>ANSWER:</b> <b>Suez</b> Canal
6. This man founded Saint Petersburg in 1703. (+) He visited Western Europe in disguise. For the point,
name this tsar.
<b>ANSWER:</b> <b>Peter the Great</b> [or Peter I]
7. This 1863 battle in Pennsylvania was a Union victory. (+) Lincoln gave an address there. For the
point, name it.
<b>ANSWER:</b> Battle of <b>Gettysburg</b>
8. This queen allied with Mark Antony. (+) She was the last active Ptolemaic ruler. For the point, name
her.
<b>ANSWER:</b> <b>Cleopatra</b> VII
